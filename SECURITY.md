# Security Policy

## Supported Versions

Due to resource limitations, we do not currently do updates for older versions of the RDKit.

Fixes to security vulnerabilities, like bug fixes, are handled as part of the standard release cycle and incorporated into the next minor release. 
We do those on a monthly basis.

## Reporting a Vulnerability

We really prefer that these problems are reported as standard bugs using the Github issue tracker.
If you have some specific reason to not want to do that, feel free to report a vulnerability using Github's "Security and quality" tab.
